# Smart Rent System 🏠💸

An interactive, responsive web application for calculating, splitting, and managing household/rental expenses and utility bills among roommates or tenants.

Live Demo: https://smartrentsystem.netlify.app/

---

## ✨ Features

- **Rent & Utility Calculation**: Calculate rent and split shared utility bills (electricity, water, Wi-Fi, maintenance, etc.) easily.
- **Per-Person Breakdown**: Detailed breakdown of how much each tenant or roommate owes.
- **Responsive UI**: Sleek, modern interface designed to work seamlessly on desktops, tablets, and mobile devices.
- **Instant Result Summaries**: Quick-view cards summarizing total rent, shared expenses, and individual share.
- **Easy Reset & Recalculate**: Quick clear/reset buttons to compute new values instantly.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Custom Properties, Modern Responsive Layouts
- **Deployment**: Netlify
